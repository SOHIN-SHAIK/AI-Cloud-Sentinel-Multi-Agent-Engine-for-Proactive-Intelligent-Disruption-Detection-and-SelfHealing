# AI Cloud Sentinel

AI Cloud Sentinel is a cloud monitoring and intelligent disruption detection system designed to analyze service logs and identify abnormal system behaviour across monitored environments. The system focuses on improving operational reliability through automated monitoring, anomaly detection, and alert-driven remediation workflows.

## Overview
Modern cloud environments generate large volumes of operational logs and monitoring signals. Detecting disruptions early and responding quickly is critical for maintaining service reliability.

AI Cloud Sentinel provides a monitoring interface that helps observe system activity, identify anomalies in service behaviour, and support automated response workflows for maintaining system stability.

## Key Features
• Cloud service log monitoring and anomaly detection  
• Real-time observability dashboard for system health insights  
• Automated alerting and disruption monitoring workflows  
• Visualization of system activity and monitoring signals  
• Modular design supporting scalable monitoring systems

## Tech Stack
Frontend: React, TypeScript, Vite  
UI: TailwindCSS  
Monitoring Interface: Custom observability dashboard

## Use Case
The system is designed to support cloud infrastructure monitoring scenarios where engineers need visibility into system health, disruption detection, and operational monitoring signals.

## Project Scope
This repository contains the monitoring interface and system components used for visualizing operational insights from monitored environments.
