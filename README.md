# AI Cloud Sentinel

AI Cloud Sentinel is a cloud monitoring and intelligent disruption detection system designed to analyze service logs and identify abnormal system behaviour across monitored environments. The system focuses on improving operational reliability through automated monitoring, anomaly detection, and alert-driven remediation workflows.

---

## Overview

Modern cloud environments generate large volumes of operational logs and monitoring signals. Detecting disruptions early and responding quickly is critical for maintaining service reliability.

AI Cloud Sentinel provides a monitoring interface that helps observe system activity, identify anomalies in service behaviour, and support automated response workflows for maintaining system stability.

---

## System Architecture

The system follows a modular monitoring architecture designed to process operational logs and detect anomalies in cloud environments.

Workflow:

Logs → Monitoring Agents → Anomaly Detection → Alert Generation → Validation Pipeline → Dashboard Visualization

Monitoring agents analyze system signals and generate alerts when abnormal patterns are detected.  
The evaluation pipeline validates these alerts using deterministic verification scripts before presenting results in the monitoring dashboard.

## Evaluation Pipeline

To ensure reliability of monitoring agent outputs, the repository includes a lightweight evaluation pipeline.

The pipeline validates anomaly detection results using deterministic verification scripts.

### Evaluation Workflow

1. System logs are provided as input  
2. Monitoring agents analyze logs and generate anomaly alerts  
3. The evaluation pipeline validates generated alerts  
4. Python verification scripts confirm that detected anomalies match expected results  

### Pipeline Structure
evaluation_pipeline/
task.md # Task definition and evaluation constraints
sample_logs.txt # Example monitoring logs used for testing
expected_output.txt # Expected anomaly detection output
validator.py # Python script verifying anomaly detection results
run_evaluation.py # Script to execute the validation pipeline


This evaluation workflow helps ensure reproducible and verifiable monitoring outputs.
